# AI Face Swap Project / AI换脸项目

![分类](https://img.shields.io/badge/分类-AI图像-purple)

## 项目简介

AI换脸技能项目。基于深度学习的面部替换，支持图片和视频换脸。

## 功能特性

- 图片换脸：单张图片的面部替换
- 视频换脸：逐帧处理实现视频换脸
- 多人脸支持：图片中存在多人时指定目标
- 质量调节：控制换脸的自然度和融合度

## 技术栈

- 深度学习面部检测与对齐
- GAN-based 面部生成
- 面部融合与后处理
