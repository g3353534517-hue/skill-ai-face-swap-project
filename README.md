# AI Face Swap Video Project / AI 虚拟形象换脸视频项目

![分类](https://img.shields.io/badge/分类-创意工具-green)

## 项目简介

复刻推特爆款 AI 换脸视频案例的完整项目。采用三层脸叠加架构，从零开始搭建到输出完整视频，涉及 FaceFusion、Deep-Live-Cam、GPT-Image 等工具链。

## 功能特性

- AI虚拟形象换脸视频项目
- 项目目标
- 原案例
- 技术架构：三层脸叠加
- 具体技术栈
- 1. 生成AI小孩人设脸
- 2. 换脸引擎
- 3. 视频流程
- 4. 转场效果建议
- 关键难点和注意事项
- 一致性（最重要）
- 脸部融合三要素
- 效果预期
- 值得关注的技术进展
- 环境信息

## 使用示例

```
真人脸部 → AI小孩脸(固定人设) → 名人/角色脸(每期目标)
```
